# 🚀 Day 10– Performance Optimization  
**Databricks 14 Days AI Challenge**

---

## 📌 Overview

Day 10 focused on **performance optimization techniques** in Databricks to improve query execution speed and overall system efficiency. The emphasis was on understanding execution plans, optimizing data layout, and benchmarking performance improvements in large-scale data pipelines.

---

## 📘 Learnings

- Query execution plans and how Spark executes queries  
- Partitioning strategies for large Delta tables  
- OPTIMIZE and Z-ORDER for data skipping and performance gains  
- Caching techniques for repeated and iterative queries  

---

## 🛠️ Tasks Completed

1. Analyzed query execution plans  
2. Partitioned large Delta tables  
3. Applied Z-ORDER optimization  
4. Benchmarked performance improvements  

---

## 💡 Key Takeaways

- Execution plans reveal **performance bottlenecks**
- Partitioning reduces **unnecessary data scans**
- **Z-ORDER** improves data skipping for selective queries
- Caching speeds up **repeated computations**
- Performance optimization is critical for **production-scale systems**
