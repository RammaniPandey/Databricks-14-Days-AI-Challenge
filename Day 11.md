# 📅 Day 11 – Statistical Analysis & ML Preparation  
**Databricks 14 Days AI Challenge**

---

## 📌 Overview

Day 11 focused on **statistical analysis and machine learning preparation**, bridging the gap between data engineering and ML. The goal was to understand data behavior using statistics, validate assumptions through hypothesis testing, and engineer meaningful features for downstream ML models.

---

## 📘 Learnings

- **Descriptive Statistics** for understanding data distributions  
- **Hypothesis Testing** to validate assumptions (weekday vs weekend behavior)  
- **A/B Test Design** fundamentals for experimentation  
- **Feature Engineering** for machine learning readiness  

---

## 🛠️ Tasks Completed

1. Calculated statistical summaries  
2. Tested hypotheses (weekday vs weekend conversions)  
3. Identified correlations between variables  
4. Engineered features for ML pipelines  

---

## 💡 Key Takeaways

- Descriptive statistics provide **first-level insights** into data quality and behavior  
- Hypothesis testing helps validate **data-driven assumptions**  
- A/B testing principles are essential for **experimentation and product analytics**  
- Feature engineering significantly impacts **ML model performance**  
- Statistical analysis is a critical step before building ML models
