# 📅 DAY 8 (16/01/26) – Unity Catalog Governance

## 📌 Overview
Day 8 focuses on **data governance and access control** using **Databricks Unity Catalog**.  
Unity Catalog provides centralized governance for data, analytics, and AI assets across the Lakehouse.

---

## 📘 Learnings

- **Catalog → Schema → Table hierarchy**
- **Access control** using GRANT / REVOKE
- **Data lineage** tracking
- **Managed vs External tables**

---

## 🛠️ Hands-on Tasks

1. Create catalogs and schemas  
2. Register Delta tables in Unity Catalog  
3. Set up fine-grained permissions  
4. Create views for controlled access
