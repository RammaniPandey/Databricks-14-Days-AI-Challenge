# 📅 Day 12 – MLflow Basics  
**Databricks 14 Days AI Challenge**

---

## 📌 Overview

Day 12 introduced **MLflow**, focusing on the fundamentals of **MLOps** and how machine learning experiments can be tracked, compared, and managed systematically. The session covered experiment tracking, model logging, and using the MLflow UI to evaluate different runs.

This day bridges **machine learning development** with **production readiness**.

---

## 📘 Learnings

- MLflow core components:
  - Tracking
  - Models
  - Model Registry
- Experiment tracking for reproducibility
- Logging parameters, metrics, and models
- Navigating and using the MLflow UI
- Comparing multiple experiment runs

---

## 🛠️ Tasks Completed

1. Trained a simple **regression model**
2. Logged **parameters, metrics, and model artifacts**
3. Viewed experiments in the **MLflow UI**
4. Compared multiple runs to evaluate performance

---

## 💡 Key Takeaways

- MLflow enables **reproducible ML experiments**
- Centralized tracking simplifies **model comparison**
- Logging parameters and metrics improves **experiment transparency**
- MLflow UI provides a clear view of **experiment history**
- Essential foundation for **production-grade MLOps**
